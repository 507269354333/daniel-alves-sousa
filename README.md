# Daniel Alves Sousa — Portfólio Profissional

Portfólio estático focado em Mercado de Capitais, Ofertas Públicas, Fundos, Distribuição e Regulação.

## Estrutura

- `index.html` — conteúdo e estrutura semântica
- `assets/portfolio.css` — stylesheet consolidado de produção
- `assets/app.js` — interações consolidadas
- `assets/profile/` — fotografia profissional
- `assets/logos/` — marcas usadas na trajetória
- `assets/favicon.svg` — ícone do site
- `site.webmanifest` — metadados de instalação
- `robots.txt` e `sitemap.xml` — indexação

## Deploy

O deploy é realizado automaticamente pela Vercel a partir da branch `main`.

## Manutenção

Ao atualizar conteúdo profissional, priorize alterações no `index.html`. Para ajustes visuais ou de interação, use os arquivos consolidados em `assets/`.
